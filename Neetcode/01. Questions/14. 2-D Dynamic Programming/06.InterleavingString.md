# 97. Interleaving String

Given strings s1, s2, and s3, find whether s3 is formed by an interleaving of s1 and s2. An interleaving preserves the relative order of characters from each string.
**Example 1:**

```
Input: s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"
Output: true
```
**Example 2:**

```
Input: s1 = "aabcc", s2 = "dbbca", s3 = "aadbbbaccc"
Output: false
```
**Example 3:**

```
Input: s1 = "", s2 = "", s3 = ""
Output: true
```

Constraints:
- 0 <= s1.length, s2.length <= 100
- 0 <= s3.length <= 200
- s1, s2, s3 consist of lowercase English letters

---

## Solution

### Intuition

`dp(i, j)` represents whether `s3[:i+j]` can be formed by interleaving `s1[:i]` and `s2[:j]`. At each position in s3, the next character must come from either s1 or s2. The position in s3 is determined by `i + j` because interleaving consumes characters strictly in order.

**Recurrence:**
- `dp(i, j) = (dp(i-1, j) and s1[i-1] == s3[i+j-1]) or (dp(i, j-1) and s2[j-1] == s3[i+j-1])`
- Base case: `dp(0, 0) = True`, first row and column check prefix matches

### Approach 1: Top-down memoization

Define `dp(i, j)` as whether `s3[:i+j]` can be interleaved from `s1[:i]` and `s2[:j]`. Try consuming the next s3 character from either source. Cache each `(i, j)` pair.

```python
class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        m, n = len(s1), len(s2)
        if m + n != len(s3):
            return False

        memo = {}

        def dp(i: int, j: int) -> bool:
            if i == m and j == n:
                return True
            if (i, j) in memo:
                return memo[(i, j)]
            k = i + j
            take_s1 = i < m and s1[i] == s3[k] and dp(i + 1, j)
            take_s2 = j < n and s2[j] == s3[k] and dp(i, j + 1)
            memo[(i, j)] = take_s1 or take_s2
            return memo[(i, j)]

        return dp(0, 0)
```

### Approach 2: Bottom-up tabulation

Fill an `(m+1) x (n+1)` boolean table. The first row and column check prefix matches using only one string. Each interior cell propagates reachability from above (consume s1) or from the left (consume s2).

```python
class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        m, n = len(s1), len(s2)
        if m + n != len(s3):
            return False

        dp = [[False] * (n + 1) for _ in range(m + 1)]
        dp[0][0] = True

        for i in range(1, m + 1):
            dp[i][0] = dp[i-1][0] and s1[i-1] == s3[i-1]

        for j in range(1, n + 1):
            dp[0][j] = dp[0][j-1] and s2[j-1] == s3[j-1]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                k = i + j - 1
                from_s1 = dp[i-1][j] and s1[i-1] == s3[k]
                from_s2 = dp[i][j-1] and s2[j-1] == s3[k]
                dp[i][j] = from_s1 or from_s2

        return dp[m][n]
```

> The index `k = i + j - 1` maps the 2-D pointer `(i, j)` back to the position in s3. This works because interleaving consumes characters strictly in order.

### Complexity

- **Time:** O(m * n). Every (i, j) cell is computed once.
- **Space:** O(m * n) for the 2-D table. Reducible to O(n) using a rolling row.

### Key concepts to review

- [[Dynamic Programming]] - 2-D boolean reachability DP on two string pointers.
- [[Memoization]] - an explicit dictionary on `(i, j)` gives the equivalent O(m*n) top-down solution.
- [[DFS|Depth-First Search]] - alternative: DFS/backtracking with memoization on `(i, j)`.
- [[02.LongestCommonSubsequence]] - the same 2-D string-DP shape (a grid indexed by two string pointers).

### Common pitfalls

- Forgetting the early `len` check: if `m + n != len(s3)`, return False immediately.
- Using `i + j` instead of `i + j - 1` to index s3 in the tabulation (off-by-one with 1-indexed table).
- Not handling the base cases for the first row and column, leaving them False when they should propagate True.
- Attempting a greedy approach: when a character matches both s1 and s2, greedy choice can lead to a dead end that backtracking (or DP) avoids.
