# [312. Burst Balloons](https://leetcode.com/problems/burst-balloons/)

You are given n balloons indexed 0 to n-1. Each balloon has a number nums\[i\]. If you burst balloon i, you get nums\[i-1\] * nums\[i\] * nums\[i+1\] coins (out-of-bounds treated as 1). Return the maximum coins you can collect by bursting all balloons wisely.
**Example 1:**

```
Input: nums = [3,1,5,8]
Output: 167
```
**Example 2:**

```
Input: nums = [1,5]
Output: 10
```

Constraints:
- n == nums.length
- 1 <= n <= 300
- 0 <= nums\[i\] <= 100

---

## Solution

### Intuition

`dp[l][r]` represents the maximum coins obtainable by bursting all balloons in the open interval `(l, r)` of the padded array (where `arr[0] = arr[n+1] = 1`). The key insight is to think about which balloon is burst **last** in a subrange rather than first. If balloon `k` is burst last in `(l, r)`, at that moment its neighbors are `arr[l]` and `arr[r]` (the boundary sentinels), giving coins `arr[l] * arr[k] * arr[r]`. The subproblems `dp[l][k]` and `dp[k][r]` are independent because `k` is still present as a wall when they are solved.

**Recurrence:**
- `dp[l][r] = max(arr[l]*arr[k]*arr[r] + dp[l][k] + dp[k][r])` for all `k` in `(l, r)`
- Base case: `dp[l][r] = 0` when `r - l < 2` (no balloons in the open interval)

This is an interval [[Dynamic Programming]] problem.

### Approach 1: Top-down with memoization

```python
class Solution:
    def maxCoins(self, nums: list[int]) -> int:
        # Pad with boundary sentinels of value 1
        arr = [1] + nums + [1]
        n = len(arr)
        memo = {}

        def dp(l: int, r: int) -> int:
            # No balloons to burst in open interval (l, r)
            if r - l < 2:
                return 0
            if (l, r) in memo:
                return memo[(l, r)]
            best = 0
            # Try each balloon k as the last one burst in (l, r)
            for k in range(l + 1, r):
                # k is last: its neighbors at burst time are arr[l] and arr[r]
                coins = arr[l] * arr[k] * arr[r] + dp(l, k) + dp(k, r)
                best = max(best, coins)
            memo[(l, r)] = best
            return best

        return dp(0, n - 1)
```

The memoized version discovers intervals only when recursion needs them. Cache hits avoid solving the same open interval twice.

### Approach 2: Bottom-up tabulation

Fill the table by increasing subarray length. Smaller intervals must be solved before larger ones, so iterate `length` from 2 to n-1. Use the same "last balloon burst" recurrence.

```python
class Solution:
    def maxCoins(self, nums: list[int]) -> int:
        arr = [1] + nums + [1]
        n = len(arr)
        # dp[l][r] = max coins from bursting all balloons in open interval (l, r)
        dp = [[0] * n for _ in range(n)]

        # Iterate by increasing interval length (need smaller intervals first)
        for length in range(2, n):
            for l in range(n - length):
                r = l + length
                # Try each k as the last balloon to burst in (l, r)
                for k in range(l + 1, r):
                    coins = arr[l] * arr[k] * arr[r] + dp[l][k] + dp[k][r]
                    dp[l][r] = max(dp[l][r], coins)

        return dp[0][n - 1]
```

> The interval must be processed in order of **increasing length** because `dp[l][r]` depends on `dp[l][k]` and `dp[k][r]`, which are strictly shorter intervals. Going bottom-up from length 2 (a single balloon between two sentinels) up to length n-1 (the full array) guarantees all dependencies are resolved before they are needed.

### Complexity

- **Time:** O(n^3). Three nested loops over intervals and choices of k.
- **Space:** O(n^2) for the dp table.

### Key concepts to review

- [[Dynamic Programming]] - interval DP. Subproblem is a contiguous range of balloons.
- [[Divide and Conquer]] - the "last balloon" decomposition splits the problem into two independent subproblems.
- [[Memoization]] - top-down with an explicit dictionary on `(l, r)` is natural given the interval structure.
- [[Recursion]] - the recurrence is easiest to see as a recursive "which k is last" enumeration.
- [[09.EditDistance]] - compare with this problem for a different kind of 2-D DP (neighbor-based cells vs. a split-point choice).

### Common pitfalls

- Thinking about which balloon is burst **first** instead of **last**: bursting first changes the neighbors of remaining balloons, making subproblems dependent. "Last burst" keeps boundaries fixed.
- Forgetting to pad with sentinel 1s on both sides. Without them, edge balloons would access out-of-bounds indices.
- Iterating `length` from largest to smallest (bottom-up must go small to large).
- Including the boundary indices l and r as candidates for k. They are sentinel walls, not burst candidates. k must be strictly inside `(l, r)`.
