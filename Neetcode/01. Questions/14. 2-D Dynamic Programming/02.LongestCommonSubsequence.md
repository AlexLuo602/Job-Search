# [1143. Longest Common Subsequence](https://leetcode.com/problems/longest-common-subsequence/)


Given two strings text1 and text2, return the length of their longest common subsequence. If there is no common subsequence, return 0.

A subsequence of a string is a new string generated from the original string with some characters (can be none) deleted without changing the relative order of the remaining characters.

For example, "ace" is a subsequence of "abcde".
A common subsequence of two strings is a subsequence that is common to both strings.
**Example 1:**

![[longest-common-subsequence-example.svg]]

```
Input: text1 = "abcde", text2 = "ace" 
Output: 3  
Explanation: The longest common subsequence is "ace" and its length is 3.
```
**Example 2:**

```
Input: text1 = "abc", text2 = "abc"
Output: 3
Explanation: The longest common subsequence is "abc" and its length is 3.
```
**Example 3:**

```
Input: text1 = "abc", text2 = "def"
Output: 0
Explanation: There is no such common subsequence, so the result is 0.
```

Constraints:

- 1 <= text1.length, text2.length <= 1000
- text1 and text2 consist of only lowercase English characters.

---

## Solution

### Intuition

`dp(i, j)` represents the LCS length of `text1[:i]` and `text2[:j]`. When the current characters match, extend the LCS of the shorter prefixes: `dp(i, j) = 1 + dp(i-1, j-1)`. When they do not match, skip one character from either string and take the better result: `dp(i, j) = max(dp(i-1, j), dp(i, j-1))`.

**Recurrence:**
- Match: `dp(i, j) = 1 + dp(i-1, j-1)`
- Mismatch: `dp(i, j) = max(dp(i-1, j), dp(i, j-1))`
- Base case: `dp(0, j) = dp(i, 0) = 0` (empty prefix has LCS length 0)

### Approach 1: Top-down memoization

Define `dp(i, j)` as the LCS length for `text1[:i]` and `text2[:j]`. When characters match, the answer extends the diagonal subproblem. When they mismatch, try dropping one character from each string and take the maximum. Cache every result so each `(i, j)` pair is solved once.

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        memo = {}

        def dp(i: int, j: int) -> int:
            if (i, j) in memo:
                return memo[(i, j)]
            if i == 0 or j == 0:
                memo[(i, j)] = 0
            elif text1[i-1] == text2[j-1]:
                memo[(i, j)] = 1 + dp(i - 1, j - 1)
            else:
                memo[(i, j)] = max(dp(i - 1, j), dp(i, j - 1))
            return memo[(i, j)]

        return dp(len(text1), len(text2))
```

### Approach 2: Bottom-up tabulation

Build an `(m+1) x (n+1)` table with an extra row and column of zeros as the empty-string base case. Fill row by row. The final answer sits at `dp[m][n]`.

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i-1] == text2[j-1]:
                    dp[i][j] = 1 + dp[i-1][j-1]
                else:
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1])

        return dp[m][n]

    def longestCommonSubsequence_optimized(self, text1: str, text2: str) -> int:
        n = len(text2)
        prev = [0] * (n + 1)
        for ch1 in text1:
            curr = [0] * (n + 1)
            for j, ch2 in enumerate(text2, 1):
                if ch1 == ch2:
                    curr[j] = 1 + prev[j-1]
                else:
                    curr[j] = max(prev[j], curr[j-1])
            prev = curr
        return prev[n]
```

> The empty row and column (`dp[0][*] = dp[*][0] = 0`) represent the LCS when one string is empty, which is always 0. This avoids separate boundary checks inside the loop.

### Complexity

- **Time:** O(m * n). Every (i, j) pair is computed once.
- **Space:** O(m * n) for the 2-D table. O(n) for the rolling 1-D version.

### Key concepts to review

- [[Dynamic Programming]] - two-string DP with diagonal, top, and left dependencies.
- [[Memoization]] - top-down alternative caching each `(i, j)` result in an explicit dictionary.
- [[Space-Time Tradeoff]] - rolling row reduces space from O(m*n) to O(n).
- [[08.DistinctSubsequences]] - similar two-string DP table shape.
- [[09.EditDistance]] - also uses diagonal + adjacent cells but counts operations.

### Common pitfalls

- Using 0-indexed dp without the extra padding row/col, requiring ugly boundary checks.
- Forgetting that when characters differ, you take the max of skipping from either string (not just one).
- Confusing LCS (longest common subsequence) with longest common substring (substring must be contiguous).
- Reducing space to 1-D but forgetting to preserve the diagonal value before overwriting it.
