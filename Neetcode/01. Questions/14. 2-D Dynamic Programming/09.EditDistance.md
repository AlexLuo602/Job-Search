# [72. Edit Distance](https://leetcode.com/problems/edit-distance/)

Given two strings word1 and word2, return the minimum number of operations required to convert word1 to word2.

You have the following three operations permitted on a word:

- Insert a character
- Delete a character
- Replace a character
**Example 1:**

![[edit-distance-example.svg]]

```
Input: word1 = "horse", word2 = "ros"
Output: 3
Explanation: 
horse -> rorse (replace 'h' with 'r')
rorse -> rose (remove 'r')
rose -> ros (remove 'e')
```
**Example 2:**

```
Input: word1 = "intention", word2 = "execution"
Output: 5
Explanation: 
intention -> inention (remove 't')
inention -> enention (replace 'i' with 'e')
enention -> exention (replace 'n' with 'x')
exention -> exection (replace 'n' with 'c')
exection -> execution (insert 'u')
```

Constraints:

- 0 <= word1.length, word2.length <= 500
- word1 and word2 consist of lowercase English letters.

---

## Solution

### Intuition

`dp(i, j)` represents the minimum edit distance to convert `word1[:i]` into `word2[:j]`. When the current characters match, no operation is needed: `dp(i, j) = dp(i-1, j-1)`. When they differ, take 1 plus the minimum of three options.

**Recurrence:**
- Match: `dp(i, j) = dp(i-1, j-1)`
- Mismatch: `dp(i, j) = 1 + min(dp(i-1, j), dp(i, j-1), dp(i-1, j-1))`
  - `dp(i-1, j)`: delete from word1
  - `dp(i, j-1)`: insert into word1 to match word2
  - `dp(i-1, j-1)`: replace the current character
- Base case: `dp(i, 0) = i` (delete i characters). `dp(0, j) = j` (insert j characters).

This is the classic Levenshtein distance [[Dynamic Programming]] recurrence on two string indices.

### Approach 1: Top-down memoization

Define `dp(i, j)` as the minimum operations to convert `word1[:i]` to `word2[:j]`. When one string is exhausted, the remaining characters of the other string determine the cost. Cache every `(i, j)` pair.

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        memo = {}

        def dp(i: int, j: int) -> int:
            if (i, j) in memo:
                return memo[(i, j)]
            # Base cases: one string exhausted
            if i == 0:
                result = j  # insert all remaining chars of word2
            elif j == 0:
                result = i  # delete all remaining chars of word1
            elif word1[i-1] == word2[j-1]:
                result = dp(i-1, j-1)  # characters match: no operation needed
            else:
                result = 1 + min(
                    dp(i-1, j),    # delete word1[i-1]
                    dp(i, j-1),    # insert word2[j-1] into word1
                    dp(i-1, j-1),  # replace word1[i-1] with word2[j-1]
                )
            memo[(i, j)] = result
            return result

        return dp(m, n)
```

### Approach 2: Bottom-up tabulation

Build an `(m+1) x (n+1)` table where `dp[i][0] = i` (delete i characters) and `dp[0][j] = j` (insert j characters) as base cases. Fill row by row to compute `dp[m][n]`. A 1-D rolling row is also possible since each row only depends on the previous row and the current row to the left.

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        # dp[i][j] = min operations to convert word1[:i] to word2[:j]
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # Base case: convert to/from empty string
        for i in range(m + 1):
            dp[i][0] = i  # delete i characters from word1
        for j in range(n + 1):
            dp[0][j] = j  # insert j characters to match word2

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i-1] == word2[j-1]:
                    dp[i][j] = dp[i-1][j-1]  # characters match: free step
                else:
                    dp[i][j] = 1 + min(
                        dp[i-1][j],    # delete from word1
                        dp[i][j-1],    # insert into word1
                        dp[i-1][j-1],  # replace
                    )

        return dp[m][n]

    def minDistance_optimized(self, word1: str, word2: str) -> int:
        # 1-D rolling row
        m, n = len(word1), len(word2)
        prev = list(range(n + 1))  # base case: dp[0][j] = j

        for i in range(1, m + 1):
            curr = [i] + [0] * n  # base case: dp[i][0] = i
            for j in range(1, n + 1):
                if word1[i-1] == word2[j-1]:
                    curr[j] = prev[j-1]
                else:
                    curr[j] = 1 + min(prev[j], curr[j-1], prev[j-1])
            prev = curr

        return prev[n]
```

> `dp[i][0] = i` and `dp[0][j] = j` represent transforming to or from an empty string: it costs exactly i deletions or j insertions. Forgetting these base cases or setting them to 0 will corrupt the entire table since every cell depends on its neighbors transitively reaching the boundary.

Matches at o==o and r==r are free diagonal moves. Mismatches pick the cheapest of delete, insert, and replace from three neighboring cells.

### Complexity

- **Time:** O(m * n). Each (i, j) pair is computed once.
- **Space:** O(m * n) for the 2-D table. O(n) for the rolling 1-D version.

### Key concepts to review

- [[Dynamic Programming]] - Levenshtein distance. Three-way recurrence (delete, insert, replace).
- [[Memoization]] - top-down with an explicit dictionary on `(i, j)` is equivalent and often easier to derive first.
- [[Space-Time Tradeoff]] - rolling row reduces space from O(m*n) to O(n).
- [[02.LongestCommonSubsequence]] - also a 2-D string DP. LCS can be used to derive edit distance.
- [[08.DistinctSubsequences]] - sibling 2-D string DP. Compare the recurrence structures.

### Common pitfalls

- Forgetting that `dp[i][0] = i` (not 0). Converting to an empty string costs i deletions.
- Confusing which dimension is word1 vs word2. The mismatch case uses all three neighbors (`dp[i-1][j]`, `dp[i][j-1]`, `dp[i-1][j-1]`).
- In the 1-D version, not saving the diagonal value (`prev[j-1]`) before overwriting the row.
- Returning `dp[n][m]` instead of `dp[m][n]` when rows index word1 and columns index word2.
