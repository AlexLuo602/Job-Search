# [10. Regular Expression Matching](https://leetcode.com/problems/regular-expression-matching/)

Given an input string s and a pattern p, implement regular expression matching with support for:
- '.' matches any single character
- '*' matches zero or more of the preceding element

The matching must cover the entire input string.
**Example 1:**

```
Input: s = "aa", p = "a"
Output: false
```
**Example 2:**

```
Input: s = "aa", p = "a*"
Output: true
```
**Example 3:**

```
Input: s = "ab", p = ".*"
Output: true
```

Constraints:
- 1 <= s.length <= 20
- 1 <= p.length <= 30
- s contains only lowercase English letters
- p contains lowercase English letters, '.', and '*'
- Each '*' has a valid preceding character

---

## Solution

### Intuition

`dp(i, j)` represents whether `s[:i]` matches `p[:j]`. The tricky case is `*`: the pattern character `p[j-1]` being `*` means we can either skip the `x*` pair entirely (zero occurrences, look at `dp(i, j-2)`) or, if the preceding pattern character matches the current s character, consume one s character and stay at the same pattern position (look at `dp(i-1, j)`).

**Recurrence:**
- `*` case: `dp(i, j) = dp(i, j-2)` (zero uses) OR `(char_matches and dp(i-1, j))` (one more use)
- Non-`*` case: `dp(i, j) = dp(i-1, j-1)` when `s[i-1] == p[j-1]` or `p[j-1] == '.'`
- Base case: `dp(0, 0) = True`. For `dp(0, j)`, patterns like `a*b*` can match empty s by collapsing each `x*` pair via `dp(0, j) = dp(0, j-2)` when `p[j-1] == '*'`.

This is a 2-D [[Dynamic Programming]] problem on string and pattern indices.

### Approach 1: Top-down with memoization

```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        m, n = len(s), len(p)
        memo = {}

        def dp(i: int, j: int) -> bool:
            if (i, j) in memo:
                return memo[(i, j)]
            # Both exhausted: full match
            if j == n:
                result = i == m
            else:
                # Check if current characters match (single char or '.')
                first_match = i < m and (p[j] == '.' or p[j] == s[i])
                if j + 1 < n and p[j + 1] == '*':
                    # x* case: skip the pair (zero uses) OR use one and stay at j
                    result = dp(i, j + 2) or (first_match and dp(i + 1, j))
                else:
                    result = first_match and dp(i + 1, j + 1)
            memo[(i, j)] = result
            return result

        return dp(0, 0)
```

### Approach 2: Bottom-up tabulation

Build an `(m+1) x (n+1)` boolean table. `dp[0][0] = True` (both empty). Base cases for `dp[0][j]` handle patterns like `a*b*c*` that can match the empty string via zero-use `*` pairs. Fill row by row.

```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        m, n = len(s), len(p)
        # dp[i][j] = does s[:i] match p[:j]?
        dp = [[False] * (n + 1) for _ in range(m + 1)]
        dp[0][0] = True  # empty string matches empty pattern

        # Base case: patterns like a*, a*b*, a*b*c* can match empty s
        for j in range(2, n + 1):
            if p[j-1] == '*':
                dp[0][j] = dp[0][j-2]  # zero uses of x* pair

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if p[j-1] == '*':
                    # Zero uses of the x* pair: skip both p[j-2] and p[j-1]
                    dp[i][j] = dp[i][j-2]
                    # One or more uses: preceding char must match s[i-1]
                    if p[j-2] == '.' or p[j-2] == s[i-1]:
                        dp[i][j] = dp[i][j] or dp[i-1][j]
                elif p[j-1] == '.' or p[j-1] == s[i-1]:
                    # Single character match: advance both pointers
                    dp[i][j] = dp[i-1][j-1]

        return dp[m][n]
```

> `dp[0][j]` for patterns with `*` is the trickiest base case. A pattern like `a*b*` can match the empty string because each `x*` pair can be used zero times. The rule `dp[0][j] = dp[0][j-2]` when `p[j-1]=='*'` handles this by "collapsing" the pair. Without this, `dp[i][j]` for small `i` values would remain False and propagate incorrectly.

The `c*` and `a*` pairs collapse to zero uses, letting the empty string match `c*a*`. Then `a*` consumes both `a` characters via the cell-above dependency, and `b` matches directly on the diagonal.

### Complexity

- **Time:** O(m * n). Each (i, j) pair is computed once.
- **Space:** O(m * n) for the 2-D table. The recursion stack in top-down is also O(m * n).

### Key concepts to review

- [[Dynamic Programming]] - 2-D boolean DP on (s index, pattern index). The `*` case looks back two columns.
- [[Memoization]] - top-down with an explicit dictionary on `(i, j)` is cleaner to derive from the recursive structure.
- [[Recursion]] - the branching logic for `*` (zero vs. one-or-more uses) is most natural as recursion first.
- [[0.BacktrackingGuide|Backtracking]] - naive approach without memoization explores exponential paths with `*` patterns.
- [[06.InterleavingString]] - similar 2-D string DP shape. Compare how the recurrences differ.

### Common pitfalls

- Handling `*` by looking at the current character rather than the preceding one (it is `p[j-2]` that pairs with `*`).
- Forgetting the `dp[0][j]` base cases for patterns that start with `x*` pairs (they can match the empty string).
- In the top-down version, checking `p[j+1] == '*'` (looking ahead) without verifying `j+1 < n`, causing an index error.
- Treating `.*` as a special single token rather than handling `.` and `*` independently through the general recurrence.
