# 53. Maximum Subarray

Given an integer array nums, find the contiguous subarray (containing at least one number) which has the largest sum and return its sum.

A subarray is a contiguous part of an array.

**Example 1:**

![[maximum-subarray-example.svg]]

```text
Input: nums = [-2,1,-3,4,-1,2,1,-5,4]
Output: 6
Explanation: [4,-1,2,1] has the largest sum = 6.
```

**Example 2:**

```text
Input: nums = [1]
Output: 1
```

**Example 3:**

```text
Input: nums = [5,4,-1,7,8]
Output: 23
```

Constraints:

- 1 <= nums.length <= 105
- -104 <= nums[i] <= 104

### Follow up: If you have figured out the O(n) solution, try coding another solution using the divide and conquer approach, which is more subtle.

---

## Solution

### Intuition
[[Kadane's Algorithm]] solves this with a single pass. The [[0.GreedyGuide|Greedy]] insight is: if the running sum drops below zero, it can only hurt any future subarray, so we reset it to zero and start fresh. We track the global maximum seen at each step.

### Approach: Kadane's Algorithm
Maintain a running `current` sum and a `best` result. At each element, if `current` is negative, discard it (reset to 0) before adding the new element. Update `best` after each addition.

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        best = nums[0]   # WHY: result must include at least one element
        current = 0

        for num in nums:
            if current < 0:
                current = 0  # WHY: negative prefix only hurts, discard it
            current += num
            best = max(best, current)

        return best
```

> Initializing `best = nums[0]` rather than `-inf` correctly handles all-negative arrays, where the answer is the single largest (least negative) element.

### Complexity
- **Time:** O(n). Single pass through the array.
- **Space:** O(1). Only two integer variables maintained.

### Key concepts to review
- [[Kadane's Algorithm]] - the canonical O(n) algorithm for maximum subarray sum
- [[0.GreedyGuide|Greedy]] - locally discarding negative prefixes leads to globally optimal result
- [[Dynamic Programming]] - Kadane's is also viewed as DP where dp\[i\] = max subarray ending at i
- [[Divide and Conquer]] - the follow-up O(n log n) approach splits at midpoint and merges
- [[02.Jump]] - another greedy problem tracking a running maximum in this category

### Common pitfalls
- Initializing `best = 0` instead of `nums[0]` - fails for all-negative arrays (correct answer is the maximum element, not 0).
- Resetting `current = 0` after adding `num` instead of before - misses the opportunity to start a fresh subarray at the current element.
- Confusing maximum subarray sum with maximum subarray product (different algorithm needed).
- Not handling the single-element case explicitly - the `best = nums[0]` initialization handles it.
