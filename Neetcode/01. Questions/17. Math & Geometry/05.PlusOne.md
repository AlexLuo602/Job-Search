# 66. Plus One

You are given a large integer represented as an integer array digits, where each digits[i] is the ith digit of the integer. The digits are ordered from most significant to least significant in left-to-right order. The large integer does not contain any leading 0's.

Increment the large integer by one and return the resulting array of digits.
**Example 1:**

```
Input: digits = [1,2,3]
Output: [1,2,4]
Explanation: The array represents the integer 123.
Incrementing by one gives 123 + 1 = 124.
Thus, the result should be [1,2,4].
```
**Example 2:**

```
Input: digits = [4,3,2,1]
Output: [4,3,2,2]
Explanation: The array represents the integer 4321.
Incrementing by one gives 4321 + 1 = 4322.
Thus, the result should be [4,3,2,2].
```
**Example 3:**

```
Input: digits = [9]
Output: [1,0]
Explanation: The array represents the integer 9.
Incrementing by one gives 9 + 1 = 10.
Thus, the result should be [1,0].
```

Constraints:

- 1 <= digits.length <= 100
- 0 <= digits[i] <= 9
- digits does not contain any leading 0's.

---

## Solution

### Intuition
Simulate the carry from the rightmost digit. Walk right to left: if a digit is less than 9, increment it and return immediately (no carry). If it is 9, set it to 0 and continue propagating. If all digits were 9, prepend a 1.

### Approach: Right-to-left carry propagation
Iterate from the last index to the first. If the current digit is not 9, increment it and return. Otherwise zero it and continue. After the loop, all digits were 9, so prepend `[1]`.

```python
class Solution:
    def plusOne(self, digits: list[int]) -> list[int]:
        for i in range(len(digits) - 1, -1, -1):
            if digits[i] < 9:
                digits[i] += 1   # WHY: no carry, done immediately
                return digits
            digits[i] = 0        # WHY: carry out; this digit wraps to 0

        # WHY: all digits were 9 (e.g. [9,9,9] -> [1,0,0,0])
        return [1] + digits
```

> Prepending `[1]` after the loop is correct because `digits` is all zeros at this point. `[1] + digits` builds the new array in O(n) without needing an explicit `digits.insert(0, 1)`.

### Walkthrough
digits = `[9, 9, 9]`

| i | digits[i] | < 9? | digits after |
|---|-----------|------|--------------|
| 2 | 9 | no | [9,9,0] |
| 1 | 9 | no | [9,0,0] |
| 0 | 9 | no | [0,0,0] |

Loop ends. Return `[1] + [0,0,0]` = `[1,0,0,0]`

digits = `[1,2,3]`

| i | digits[i] | < 9? | digits after |
|---|-----------|------|--------------|
| 2 | 3 | yes | [1,2,4] |

Return immediately: `[1,2,4]`

### Complexity
- **Time:** O(n). In the worst case (all 9s) every digit is visited once.
- **Space:** O(1) in-place for the common case; O(n) only when a new leading digit must be added.

### Key concepts to review
- [[Recursion]] - the carry logic can also be expressed recursively, but iteration is cleaner here
- [[07.MultiplyStrings]] - also uses carry propagation across digit arrays

### Common pitfalls
- Forgetting to handle the all-9s case, leaving a list of zeros with no leading 1.
- Using `digits.insert(0, 1)` which works but modifies in place differently from `[1] + digits`.
- Iterating left-to-right instead of right-to-left, which processes the carry in the wrong direction.
- Not returning immediately when a non-9 digit is found, unnecessarily zeroing later digits.
