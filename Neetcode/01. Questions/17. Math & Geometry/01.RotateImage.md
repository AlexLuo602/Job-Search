# 48. Rotate Image


You are given an n x n 2D matrix representing an image, rotate the image by 90 degrees (clockwise).

You have to rotate the image in-place, which means you have to modify the input 2D matrix directly. DO NOT allocate another 2D matrix and do the rotation.
**Example 1:**

![[rotate-image-example.svg]]

```
Input: matrix = [[1,2,3],[4,5,6],[7,8,9]]
Output: [[7,4,1],[8,5,2],[9,6,3]]
```
**Example 2:**

```
Input: matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
Output: [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

Constraints:

- n == matrix.length == matrix[i].length
- 1 <= n <= 20
- -1000 <= matrix[i][j] <= 1000

---

## Solution

### Intuition
A 90-degree clockwise rotation equals a transpose followed by a left-to-right row reversal. Both operations are O(1) space [[Matrix Traversal]] steps, and composing them avoids the complexity of rotating elements one ring at a time.

### Approach: Transpose + reverse each row

Step 1: Transpose the matrix (swap `matrix[i][j]` with `matrix[j][i]` for `j > i`). Step 2: Reverse each row in place.

```python
class Solution:
    def rotate(self, matrix: list[list[int]]) -> None:
        n = len(matrix)

        # Step 1: Transpose (reflect across the main diagonal)
        for i in range(n):
            for j in range(i + 1, n):  # only upper triangle to avoid double-swap
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

        # Step 2: Reverse each row (equivalent to horizontal flip)
        for row in matrix:
            row.reverse()
```

> Only iterate the upper triangle (`j` starts at `i + 1`) during the transpose. If you start `j` at 0, every swap is undone by its symmetric counterpart later in the loop.

### Walkthrough
Input: `[[1,2,3],[4,5,6],[7,8,9]]`

The `*` tracks value 3 through both steps:

```text
Original          After transpose     After row reverse
 1  2  3*           1  4  7             7  4  1
 4  5  6     →       2  5  8      →      8  5  2
 7  8  9             3* 6  9             9  6  3*
```

Output: `[[7,4,1],[8,5,2],[9,6,3]]`

### Complexity
- **Time:** O(n^2). Every element is visited a constant number of times.
- **Space:** O(1). All swaps are in-place; no extra matrix allocated.

### Key concepts to review
- [[Matrix Traversal]] - systematic in-place traversal pattern
- [[Linked List Reversal|In-place Reversal]] - used to flip each row after transposing
- [[02.SpiralMatrix]] - another in-place matrix traversal pattern
- [[03.SetMatrixZeroes]] - also modifies a matrix in-place with O(1) extra space

### Common pitfalls
- Starting the inner transpose loop at `j = 0` instead of `j = i + 1`, causing elements to be swapped back to their original positions.
- Applying the steps in reverse order (reverse rows first, then transpose) produces a counter-clockwise rotation, not clockwise.
- Allocating a new matrix and copying back, which violates the in-place constraint.
- Using the wrong diagonal: swapping `matrix[i][j]` with `matrix[n-1-j][n-1-i]` is the anti-diagonal, not the main diagonal.
