# 73. Set Matrix Zeroes

Given an m x n integer matrix matrix, if an element is 0, set its entire row and column to 0's.

You must do it in place.
**Example 1:**

![[set-matrix-zeroes-example.svg]]

```
Input: matrix = [[1,1,1],[1,0,1],[1,1,1]]
Output: [[1,0,1],[0,0,0],[1,0,1]]
```
**Example 2:**

```
Input: matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
Output: [[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

Constraints:

- m == matrix.length
- n == matrix[0].length
- 1 <= m, n <= 200
- -2<sup>31</sup> <= matrix[i][j] <= 2<sup>31</sup> - 1
 

Follow up:

- A straightforward solution using O(mn) space is probably a bad idea.
- A simple improvement uses O(m + n) space, but still not the best solution.
- Could you devise a constant space solution?

---

## Solution

### Intuition
The key insight for O(1) space: repurpose the first row and first column as flag arrays, recording which rows and columns need zeroing. A single extra variable tracks whether the first column itself should be zeroed (because `matrix[0][0]` is shared between the row-0 flag and the col-0 flag). This is a careful [[Matrix Traversal]] with a precise ordering of operations.

### Approach 1: O(m+n) space

Use separate boolean arrays `zero_rows` and `zero_cols`, then apply them. Simple but uses O(m+n) extra space.

### Approach 2: O(1) space using first row/column as flags

Use `matrix[0][j]` as the zero flag for column `j`, and `matrix[i][0]` as the zero flag for row `i`. A separate variable `col0` records whether column 0 itself is zeroed, since `matrix[0][0]` already serves as the row-0 flag.

```python
class Solution:
    def setZeroes(self, matrix: list[list[int]]) -> None:
        rows, cols = len(matrix), len(matrix[0])
        col0_zero = False  # separate flag for column 0

        # Pass 1: record zero positions into first row/column
        for i in range(rows):
            if matrix[i][0] == 0:
                col0_zero = True          # column 0 needs zeroing
            for j in range(1, cols):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0      # flag row i
                    matrix[0][j] = 0      # flag col j

        # Pass 2: zero interior cells based on flags (skip row 0 and col 0)
        for i in range(1, rows):
            for j in range(1, cols):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0

        # Pass 3: zero row 0 if matrix[0][0] was flagged
        if matrix[0][0] == 0:
            for j in range(1, cols):
                matrix[0][j] = 0

        # Pass 4: zero column 0 if col0_zero was set
        if col0_zero:
            for i in range(rows):
                matrix[i][0] = 0
```

> Passes 3 and 4 must come last. Zeroing row 0 or column 0 before Pass 2 would corrupt the flags still needed to zero the interior cells.

### Walkthrough
Input: `[[0,1,2,0],[3,4,5,2],[1,3,1,5]]`

Pass 1: `matrix[0][0]=0` flags row 0 and col 0. `matrix[0][3]=0` flags col 3. `col0_zero = True`.

Flags: row 0 = `[0,1,2,0]`, col 0 = `[0,3,1]`.

Pass 2 (interior i>=1, j>=1):
- (1,3): col 3 flagged -> 0. (2,3): col 3 flagged -> 0.

Pass 3 (zero row 0 since matrix[0][0]==0): `[0,0,0,0]`.

Pass 4 (col0_zero=True): col 0 all zero.

Output: `[[0,0,0,0],[0,4,5,0],[0,3,1,0]]`

**Marker phases for `[[1,0,3], [4,5,0], [7,8,9]]`:**

```text
Initial          Pass 1: markers      Pass 2: interior     Passes 3/4: final
 1  0  3           0* 0* 0*             0* 0* 0*             0  0  0
 4  5  0     →     0* 5  0       →      0* 0  0       →      0  0  0
 7  8  9           7  8  9              7  0  0              7  0  0
```

`0*` marks a zero in the first row or first column that stores a row or column flag. Pass 2 reads those flags before Passes 3 and 4 handle the first row and first column.

### Complexity
- **Time:** O(m * n). Four passes, each O(m * n) in the worst case.
- **Space:** O(1). Only the `col0_zero` boolean is extra; flags are stored in the matrix itself.

### Key concepts to review
- [[Matrix Traversal]] - careful multi-pass traversal with in-place flag storage
- [[Space-Time Tradeoff]] - trading clarity for O(1) space by reusing matrix cells as flags
- [[01.RotateImage]] - another in-place matrix modification problem
- [[02.SpiralMatrix]] - systematic matrix traversal

### Common pitfalls
- Zeroing the first row or column before using their values as flags in Pass 2.
- Forgetting the `col0_zero` variable: using `matrix[0][0]` alone conflates the row-0 flag with the col-0 flag.
- Starting Pass 2 from `i=0` or `j=0`, which overwrites flags before they are read.
- Applying flags during Pass 1 instead of after, which propagates false zeros to cells not yet inspected.
