# [297. Serialize and Deserialize Binary Tree](https://leetcode.com/problems/serialize-and-deserialize-binary-tree/)



Serialization is the process of converting a data structure or object into a sequence of bits so that it can be stored in a file or memory buffer, or transmitted across a network connection link to be reconstructed later in the same or another computer environment.

Design an algorithm to serialize and deserialize a binary tree. There is no restriction on how your serialization/deserialization algorithm should work. You just need to ensure that a binary tree can be serialized to a string and this string can be deserialized to the original tree structure.

Clarification: The input/output format is the same as how LeetCode serializes a binary tree. You do not necessarily need to follow this format, so please be creative and come up with different approaches yourself.

 

**Example 1:**

![[serialize-binary-tree-example.svg]]

```
Input: root = [1,2,3,null,null,4,5]
Output: [1,2,3,null,null,4,5]
```

**Example 2:**
```
Input: root = []
Output: []
```

Constraints:

- The number of nodes in the tree is in the range [0, 104].
- -1000 <= Node.val <= 1000

## Solution

### Intuition
To serialize a [[Binary Tree]] to a string and recover it exactly, we need to encode null children explicitly. Preorder [[DFS|Depth-First Search]] is the natural choice: the root comes first, so during deserialization the first token is always the root. Null children are recorded as a sentinel (e.g., `"N"`) so the tree's structure is fully captured. The deserializer replays the same preorder sequence, consuming one token per recursive call.

### Approach: Optimal
Use recursive preorder DFS for both serialize and deserialize. Serialize writes `"val,left,right"` with `"N"` for null nodes. Deserialize uses a shared index (or iterator) to consume tokens in preorder.

```python
# TreeNode definition:
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from typing import Optional
import collections

class Codec:

    def serialize(self, root: Optional['TreeNode']) -> str:
        """Encodes a tree to a single string using preorder DFS."""
        tokens = []

        def dfs(node: Optional['TreeNode']) -> None:
            if node is None:
                tokens.append("N")  # sentinel for null
                return
            tokens.append(str(node.val))
            dfs(node.left)   # left before right (preorder)
            dfs(node.right)

        dfs(root)
        return ",".join(tokens)

    def deserialize(self, data: str) -> Optional['TreeNode']:
        """Decodes the encoded data back to a tree."""
        tokens = collections.deque(data.split(","))

        def dfs() -> Optional['TreeNode']:
            token = tokens.popleft()

            if token == "N":
                return None  # null sentinel: no node here

            # Reconstruct this node, then its left and right children
            node = TreeNode(int(token))
            node.left  = dfs()  # left child consumes next tokens
            node.right = dfs()
            return node

        return dfs()
```

> Using `collections.deque` for the token list makes `popleft()` O(1). Each recursive call pops exactly one token, so the total deserialize time is O(N). The preorder structure ensures the root token is always consumed before its children's tokens.

### Complexity
- **Time:** O(N) for both serialize and deserialize. Each node processed once.
- **Space:** O(N) for the token list (2N+1 tokens: N values, N+1 nulls). Call stack is O(H).

### Key concepts to review
- [[DFS|Depth-First Search]] - preorder DFS ensures the root token always precedes its children, enabling top-down reconstruction.
- [[String Encoding]] - the serialized format must encode null nodes explicitly; without nulls the tree structure is ambiguous.
- [[Recursion]] - deserialize mirrors the serialize DFS structure exactly; each call consumes one token.
- [[Binary Tree]] - tree serialization is a fundamental concept for persistence, network transfer, and test case generation.
- [[14.BinaryTreeMaximumPathSum]] - contrast: that problem processes subtrees without needing to reconstruct the tree.
- [[08.BinaryTreeLevelOrderTraversal]] - BFS (level-order) serialization is an alternative; the original Java solution uses this approach.

### Common pitfalls
- Not encoding null children, making it impossible to distinguish `[1,2]` from `[1,null,2]` during deserialization.
- Using a list index instead of a deque, requiring a mutable index variable or a nonlocal workaround.
- Splitting on a delimiter that can appear in node values (e.g., using `-` as a delimiter with negative numbers).
- Building the right subtree before the left during deserialization, which mismatches the preorder serialize order and produces a wrong tree.
