# [130. Surrounded Regions](https://leetcode.com/problems/surrounded-regions/)


Given an m x n matrix board containing 'X' and 'O', capture all regions that are 4-directionally surrounded by 'X'.

A region is captured by flipping all 'O's into 'X's in that surrounded region.

 

**Example 1:**

![[surrounded-regions-example.svg]]

```
Input: board = [
["X","X","X","X"],
["X","O","O","X"],
["X","X","O","X"],
["X","O","X","X"]]
Output: [
["X","X","X","X"],
["X","X","X","X"],
["X","X","X","X"],
["X","O","X","X"]]
Explanation: Surrounded regions should not be on the border, which means that any 'O' on the border of the board are not flipped to 'X'. Any 'O' that is not on the border and it is not connected to an 'O' on the border will be flipped to 'X'. Two cells are connected if they are adjacent cells connected horizontally or vertically.
```
**Example 2:**
```
Input: board = [["X"]]
Output: [["X"]]
```

Constraints:

- m == board.length
- n == board[i].length
- 1 <= m, n <= 200
- board[i][j] is 'X' or 'O'.

---

## Solution

### Intuition
An 'O' is safe (not flippable) if and only if it is connected to a border 'O'. Rather than finding all surrounded regions directly, we invert the problem: use [[DFS|Depth-First Search]] from every border 'O' to mark all safe cells, then flip every remaining 'O' to 'X'.

### Approach
In one pass, DFS from each 'O' on the four borders, marking reachable 'O's as a temporary sentinel (e.g., 'S'). In a second pass, flip all remaining 'O's to 'X' (captured) and restore all 'S's back to 'O' (safe).

```python
class Solution:
    def solve(self, board: list[list[str]]) -> None:
        rows, cols = len(board), len(board[0])
        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        def dfs(r: int, c: int) -> None:
            if r < 0 or r >= rows or c < 0 or c >= cols or board[r][c] != 'O':
                return
            board[r][c] = 'S'   # sentinel: safe, connected to border
            for dr, dc in directions:
                dfs(r + dr, c + dc)

        # Mark all 'O's connected to any border as safe
        for r in range(rows):
            dfs(r, 0)
            dfs(r, cols - 1)
        for c in range(cols):
            dfs(0, c)
            dfs(rows - 1, c)

        # Flip: surrounded 'O' -> 'X', safe 'S' -> 'O'
        for r in range(rows):
            for c in range(cols):
                if board[r][c] == 'O':
                    board[r][c] = 'X'   # captured
                elif board[r][c] == 'S':
                    board[r][c] = 'O'   # restore safe
```

> The sentinel trick ('S') lets us do the entire operation in-place with two linear passes and no extra data structures, keeping space O(1) beyond the recursion stack.

### Walkthrough
```
X X X X        X X X X        X X X X
X O O X  ->   X O O X  ->    X X X X
X X O X        X X O X        X X X X
X O X X        X S X X        X O X X
```
- Border 'O's: only (3,1). DFS from (3,1): no neighbors are 'O', so just (3,1) marked 'S'.
- Inner 'O's at (1,1),(1,2),(2,2) have no border connection - they stay 'O', get flipped to 'X'.
- (3,1) 'S' restored to 'O'.

### Complexity
- **Time:** O(m * n). Each cell processed at most twice.
- **Space:** O(m * n). Recursion stack in the worst case (entire board is 'O').

### Key concepts to review
- [[DFS|Depth-First Search]] - flood-fill from border cells to identify safe regions.
- [[Matrix Traversal]] - direction vectors for 4-directional traversal.
- [[Graph]] - 'O' cells form connected components; border-connected ones are safe.
- [[04.PacificAtlanticWaterFlow]] - similar "start from boundary" DFS inversion strategy.

### Common pitfalls
- Starting DFS from all 'O's instead of only border 'O's - misidentifies safe regions.
- Forgetting to restore the sentinel back to 'O' in the final pass.
- Only iterating two borders (e.g., top and bottom) and missing left and right column borders.
- Checking `board[r][c] == 'O'` after DFS has already changed it to 'S', causing missed captures.
