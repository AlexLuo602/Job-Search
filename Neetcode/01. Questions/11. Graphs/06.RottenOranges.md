# [994. Rotting Oranges](https://leetcode.com/problems/rotting-oranges/)


You are given an m x n grid where each cell can have one of three values:

- 0 representing an empty cell,
- 1 representing a fresh orange, or
- 2 representing a rotten orange.

Every minute, any fresh orange that is 4-directionally adjacent to a rotten orange becomes rotten.

Return the minimum number of minutes that must elapse until no cell has a fresh orange. If this is impossible, return -1.

 

**Example 1:**

![[rotting-oranges-example.svg]]

```
Input: grid = [[2,1,1],[1,1,0],[0,1,1]]
Output: 4
```
**Example 2:**
```
Input: grid = [[2,1,1],[0,1,1],[1,0,1]]
Output: -1
Explanation: The orange in the bottom left corner (row 2, column 0) is never rotten, because rotting only happens 4-directionally.
```
**Example 3:**
```
Input: grid = [[0,2]]
Output: 0
Explanation: Since there are already no fresh oranges at minute 0, the answer is just 0.
```

Constraints:

- m == grid.length
- n == grid[i].length
- 1 <= m, n <= 10
- grid[i][j] is 0, 1, or 2.

---

## Solution

### Intuition
Rotting spreads simultaneously from all rotten oranges each minute, which is the classic signature of multi-source [[BFS|Breadth-First Search]]. Seed the BFS queue with every initially rotten orange, count fresh oranges, and simulate minute by minute. When the queue empties, any remaining fresh oranges are unreachable.

### Approach
Pre-load all rotten oranges into a deque and count fresh oranges. Process BFS level by level (each level = one minute). When a fresh neighbor is infected, decrement the fresh count and enqueue the new rotten cell. After BFS, if fresh count is 0 return the elapsed minutes, else return -1.

```python
import collections


class Solution:
    def orangesRotting(self, grid: list[list[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]

        queue: collections.deque[tuple[int, int]] = collections.deque()
        fresh = 0

        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 2:
                    queue.append((r, c))   # all initial sources
                elif grid[r][c] == 1:
                    fresh += 1

        if fresh == 0:
            return 0   # no fresh oranges to rot

        minutes = 0
        while queue and fresh > 0:        # stop the moment the last orange rots
            minutes += 1
            for _ in range(len(queue)):   # process one full minute at a time
                r, c = queue.popleft()
                for dr, dc in directions:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                        grid[nr][nc] = 2   # infect the fresh orange
                        fresh -= 1
                        queue.append((nr, nc))

        return minutes if fresh == 0 else -1
```

> The `and fresh > 0` guard keeps the count exact. Without it, an unconditional `while queue` runs one extra level after the final orange rots, and that trailing level only re-expands already-rotten cells, but `minutes += 1` at the top still fires, overcounting by 1 (Example 1 would return 5 instead of 4).

### Walkthrough
grid = `[[2,1,1],[1,1,0],[0,1,1]]`, fresh=6, queue=[(0,0)]

| minute | queue start | infections | fresh after |
|--------|-------------|-----------|-------------|
| 1 | [(0,0)] | (0,1),(1,0) | 4 |
| 2 | [(0,1),(1,0)] | (0,2),(1,1) | 2 |
| 3 | [(0,2),(1,1)] | (2,1) | 1 |
| 4 | [(2,1)] | (2,2) | 0 |

Return 4.

Multi-source BFS spreads one level per minute. `R` marks the oranges that rot during that minute:

```text
Minute 0      Minute 1      Minute 2      Minute 3      Minute 4
2 1 1         2 R 1         2 2 R         2 2 2         2 2 2
1 1 ·    →    R 1 ·    →    2 R ·    →    2 2 ·    →    2 2 ·
· 1 1         · 1 1         · 1 1         · R 1         · 2 R
```

`2` = already rotten, `R` = rots now, `1` = fresh, and `·` = empty. The last fresh orange rots at minute 4.

### Complexity
- **Time:** O(m * n). Each cell enters the queue at most once.
- **Space:** O(m * n). Queue can hold all cells in the worst case.

### Key concepts to review
- [[BFS|Breadth-First Search]] - multi-source BFS where all sources are seeded simultaneously; compare single-source BFS in [[13.WordLadder]].
- [[Matrix Traversal]] - direction vectors for 4-directional spread.
- [[Graph]] - implicit grid graph; BFS gives shortest (minimum time) paths from all sources.
- [[07.WallsAndGates]] - same multi-source BFS pattern for distance filling.

### Common pitfalls
- Seeding only the first rotten orange instead of all of them - gives wrong answer when multiple initial rotten sources exist.
- Counting minutes based on queue size rather than BFS levels - overcounts or undercounts.
- Not checking for isolated fresh oranges after BFS (returning `minutes` without verifying `fresh == 0`).
- Forgetting the early return when `fresh == 0` at the start (no minutes needed).
