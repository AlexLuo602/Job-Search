# 217. Contains Duplicate

Given an integer array nums, return true if any value appears at least twice in the array, and return false if every element is distinct.

 

**Example 1:**

```text
Input: nums = [1,2,3,1]
Output: true
```

**Example 2:**

```text
Input: nums = [1,2,3,4]
Output: false
```

**Example 3:**

```text
Input: nums = [1,1,1,3,3,4,3,2,4,2]
Output: true
```

Constraints:

- 1 <= nums.length <= 105
- -109 <= nums[i] <= 109

## Solution

Scan once, keeping a `set` of values seen so far. The moment a value is already in the set, you've found a duplicate; if the scan finishes, every element was distinct.

| Element | Set after processing | Decision |
|---|---|---|
| 1 | `{1}` | Not seen, add |
| 2 | `{1,2}` | Not seen, add |
| 3 | `{1,2,3}` | Not seen, add |
| 1 | `{1,2,3}` | Already seen, return `true` |

```python
class Solution:
    def containsDuplicate(self, nums: list[int]) -> bool:
        seen = set()
        for num in nums:
            if num in seen:       # already encountered → duplicate
                return True
            seen.add(num)
        return False
```

### Complexity
- **Time:** O(n) — one pass; each set membership test and insert is O(1) average.
- **Space:** O(n) — the set stores up to n distinct values.

### Key concepts to review
- [[Set]] - O(1) average membership test is what makes the single-pass check work.
- [[Hash Map]] - a set is a hash table without values; same collision-handling machinery.
