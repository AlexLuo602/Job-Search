# 36. Valid Sudoku


Determine if a 9 x 9 Sudoku board is valid. Only the filled cells need to be validated according to the following rules:

- Each row must contain the digits 1-9 without repetition.
- Each column must contain the digits 1-9 without repetition.
- Each of the nine 3 x 3 sub-boxes of the grid must contain the digits 1-9 without repetition.

Note:
- A Sudoku board (partially filled) could be valid but is not necessarily solvable.
- Only the filled cells need to be validated according to the mentioned rules.
 

**Example 1:**

```text

[["5","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
Output: true
```

**Example 2:**

```text
Input: board = 
[["8","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
```

Explanation: Same as Example 1, except with the 5 in the top left corner being modified to 8. Since there are two 8's in the top left 3x3 sub-box, it is invalid.
 

Constraints:

- board.length == 9
- board[i].length == 9
- board[i][j] is a digit 1-9 or '.'.

## Solution

### Intuition

A board is valid when no digit repeats within any row, any column, or any 3x3 box. "Has this digit already appeared in this group?" is a membership question, which a [[Set]] answers in O(1). We keep one set per row, per column, and per box, and on each filled cell we check then record its three memberships. See [[09.LongestConsecutiveSequence]] for another problem that leans on O(1) set membership.

### Approach

Iterate over all 81 cells once. For each filled cell, derive its row index, column index, and box index `(r // 3, c // 3)`. If the digit is already present in any of those three sets, the board is invalid; otherwise add it to all three.

```python
from collections import defaultdict

class Solution:
    def isValidSudoku(self, board: list[list[str]]) -> bool:
        rows: dict[int, set[str]] = defaultdict(set)
        cols: dict[int, set[str]] = defaultdict(set)
        boxes: dict[tuple[int, int], set[str]] = defaultdict(set)  # keyed by (r//3, c//3)

        for r in range(9):
            for c in range(9):
                val = board[r][c]
                if val == ".":
                    continue                       # only filled cells are validated
                box = (r // 3, c // 3)
                if val in rows[r] or val in cols[c] or val in boxes[box]:
                    return False                   # duplicate in some group
                rows[r].add(val)
                cols[c].add(val)
                boxes[box].add(val)
        return True
```

> The box key `(r // 3, c // 3)` maps every cell to one of the nine 3x3 sub-boxes. Integer division collapses each run of three indices (0,1,2 -> 0; 3,4,5 -> 1; 6,7,8 -> 2) to a single box coordinate.

### Walkthrough

Consider the invalid Example 2 (Example 1 with the top-left `5` changed to `8`). The top-left 3x3 box now holds two 8s — one at `(0,0)` and one at `(2,2)`:

| cell (r,c) | val | box | duplicate? | action |
|------------|-----|-----|------------|--------|
| (0,0)      | 8   | (0,0) | no       | add 8 to rows[0], cols[0], boxes[(0,0)] |
| ...        | ... | ...   | ...      | ... |
| (2,2)      | 8   | (0,0) | **yes**  | `8 in boxes[(0,0)]` is True → return False |

The row-major scan reaches `(2,2)` before any other repeated 8, so the box check fires there and returns `False` immediately. The code never reaches `(3,0)`.

Output for Example 1: `True`.

### Complexity

- **Time:** O(1). The board is fixed at 9x9, so this is constant work (81 cells); in general terms it is O(n^2) for an n x n board.
- **Space:** O(1). At most 9 + 9 + 9 sets each holding at most 9 digits, a fixed bound.

### Key concepts to review

- [[Set]] - O(1) membership is what makes the duplicate check cheap.
- [[Hash Map]] - one set per row/column/box, indexed by a key, is just a map of sets.

### Common pitfalls

- Computing the box key wrong; it must be `(r // 3, c // 3)`, not `r // 3 + c // 3` (which collides across different boxes).
- Validating empty cells (`.`); only filled cells should be checked.
- Checking membership but forgetting to add the digit, so duplicates slip through.
