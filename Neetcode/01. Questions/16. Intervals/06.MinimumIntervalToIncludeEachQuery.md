# 1851. Minimum Interval to Include Each Query

You are given a 2D integer array intervals where intervals[i] = [left, right] (inclusive). The size of an interval is right - left + 1. You are also given an integer array queries. For each query, find the size of the smallest interval that contains the query value. Return -1 if none exists.
**Example 1:**

![[minimum-interval-query-example.svg]]

```text
Input: intervals = [[1,4],[2,4],[3,6],[4,4]], queries = [2,3,4,5]
Output: [3,3,1,4]
```

**Example 2:**

![[intervals-minimum-interval-query-example2.svg]]

```text
Input: intervals = [[2,3],[2,5],[1,8],[20,25]], queries = [2,19,5,22]
Output: [2,-1,4,6]
```

Constraints:
- 1 <= intervals.length, queries.length <= 10^5
- 1 <= left <= right <= 10^7
- 1 <= queries[j] <= 10^7

---

## Solution

### Intuition
Sort both intervals by start and queries by value. Sweep through queries in sorted order, adding all intervals whose left boundary has been reached. A [[Heap]] ordered by interval size keeps the smallest candidate at the top. Before reading the answer, pop any intervals from the heap that have already ended (right < query). The result for each query is the heap's top, or -1 if empty.

### Approach: Sort intervals and queries + min-heap by size

Sort intervals by left. Sort query indices by query value. For each query (in sorted order), push all intervals that start at or before the query onto a min-heap keyed by size. Evict expired intervals (right < query). Record the answer using the original query index.

```python
import heapq

class Solution:
    def minInterval(self, intervals: list[list[int]], queries: list[int]) -> list[int]:
        intervals.sort(key=lambda x: x[0])          # sort by left boundary
        sorted_qi = sorted(range(len(queries)), key=lambda i: queries[i])

        res = [0] * len(queries)
        min_heap: list[tuple[int, int]] = []         # (size, right)
        i = 0                                        # pointer into sorted intervals

        for qi in sorted_qi:
            q = queries[qi]

            # Add all intervals that have started by the time of this query
            while i < len(intervals) and intervals[i][0] <= q:
                left, right = intervals[i]
                heapq.heappush(min_heap, (right - left + 1, right))  # keyed by size
                i += 1

            # Remove intervals that have already ended before this query
            while min_heap and min_heap[0][1] < q:
                heapq.heappop(min_heap)

            res[qi] = min_heap[0][0] if min_heap else -1

        return res
```

> Queries must be processed in sorted order so that the interval pointer `i` advances monotonically. Results are stored at their original index `qi` so the output matches the original query order.

### Walkthrough
Input: `intervals = [[1,4],[2,4],[3,6],[4,4]]`, `queries = [2,3,4,5]`

Sorted queries (by value): `[2,3,4,5]` with indices `[0,1,2,3]`.

| q | Intervals pushed | Heap (size,right) | Evicted (right<q) | Answer |
|---|-----------------|-------------------|-------------------|--------|
| 2 | [1,4]->(4,4), [2,4]->(3,4) | [(3,4),(4,4)] | none | 3 |
| 3 | [3,6]->(4,6) | [(3,4),(4,4),(4,6)] | none | 3 |
| 4 | [4,4]->(1,4) | [(1,4),(3,4),(4,4),(4,6)] | none | 1 |
| 5 | none | [(1,4),(3,4),(4,4),(4,6)] | (1,4),(3,4),(4,4) evicted | 4 (from (4,6)) |

Output: `[3,3,1,4]`

### Complexity
- **Time:** O(n log n + q log q). Sorting dominates: O(n log n) for intervals plus O(q log q) for queries; each interval is pushed and popped at most once from the O(log n) heap.
- **Space:** O(n + q). Heap stores at most n intervals; result array stores q answers.

### Key concepts to review
- [[Heap]] - min-heap by size gives the smallest covering interval in O(log n)
- [[Sorting]] - sorting both intervals and queries enables the sweep-line approach
- [[0.GreedyGuide|Greedy]] - processing queries in order lets us reuse the interval pointer without backtracking
- [[05.MeetingRoomsII]] - also uses a min-heap to manage active intervals

### Common pitfalls
- Processing queries in their original order: the interval pointer would need to reset, making the sweep invalid.
- Forgetting to store answers at `qi` (the original index) rather than the sorted position.
- Evicting intervals where `right <= q` instead of `right < q`, which removes valid covering intervals.
- Keying the heap by right endpoint instead of size, which does not guarantee the smallest interval.
