# 3. Longest Substring Without Repeating Characters

Given a string s, find the length of the longest substring without repeating characters.

**Example 1:**

```text
Input: s = "abcabcbb"
Output: 3
Explanation: The answer is "abc", with the length of 3.
```

**Example 2:**

```text
Input: s = "bbbbb"
Output: 1
Explanation: The answer is "b", with the length of 1.
```

**Example 3:**

```text
Input: s = "pwwkew"
Output: 3
Explanation: The answer is "wke", with the length of 3.
Notice that the answer must be a substring, "pwke" is a subsequence and not a substring.
```

Constraints:

- 0 <= s.length <= 5 * 10^4
- s consists of English letters, digits, symbols and spaces.

---

## Solution

### Intuition
Grow a window to the right; when a character repeats inside the window, jump the left edge just past the previous occurrence of that character. A [[Hash Map]] from character to its last index lets the left pointer leap in O(1) instead of crawling. This is the canonical [[0.SlidingWindowGuide|Sliding Window]] with a [[0.TwoPointerGuide|Two Pointer]] window.

### Approach: Optimal
Keep `last_seen[ch]` = most recent index of `ch`. For each `right`, if `ch` was seen at or after the current `left`, move `left` to `last_seen[ch] + 1`. Record the window length each step.

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last_seen: dict[str, int] = {}
        max_len = 0
        left = 0
        for right, ch in enumerate(s):
            # only jump left if the repeat is INSIDE the current window
            if ch in last_seen and last_seen[ch] >= left:
                left = last_seen[ch] + 1
            last_seen[ch] = right
            max_len = max(max_len, right - left + 1)
        return max_len
```

> The guard `last_seen[ch] >= left` is essential. A stale index from before `left` must not drag the window backward; without it, `left` could move leftward and inflate the count.

### Complexity
- **Time:** O(n). Each index is visited once by `right`; `left` only advances.
- **Space:** O(min(n, charset)). The map holds at most one entry per distinct character.

### Key concepts to review
- [[0.SlidingWindowGuide|Sliding Window]] - variable-size window that shrinks from the left on a duplicate.
- [[Hash Map]] - stores last index per character for an O(1) left-pointer jump.
- [[0.TwoPointerGuide|Two Pointer]] - `left`/`right` bound the candidate substring.
- [[03.LongestRepeatingCharacterReplacement]] - sibling window problem using frequency counts.

### Common pitfalls
- Setting `left = last_seen[ch] + 1` unconditionally, which can move `left` backward for characters last seen outside the window.
- Using a `set` and crawling `left` one step at a time, which still works but is slower to reason about than index jumping.
- Off-by-one in window length: it is `right - left + 1`.
