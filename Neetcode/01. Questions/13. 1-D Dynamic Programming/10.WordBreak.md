# [139. Word Break](https://leetcode.com/problems/word-break/)


Given a string s and a dictionary of strings wordDict, return true if s can be segmented into a space-separated sequence of one or more dictionary words.

Note that the same word in the dictionary may be reused multiple times in the segmentation.

 

**Example 1:**
```
Input: s = "leetcode", wordDict = ["leet","code"]
Output: true
Explanation: Return true because "leetcode" can be segmented as "leet code".
```
**Example 2:**
```
Input: s = "applepenapple", wordDict = ["apple","pen"]
Output: true
Explanation: Return true because "applepenapple" can be segmented as "apple pen apple".
Note that you are allowed to reuse a dictionary word.
```
**Example 3:**
```
Input: s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
Output: false
```

Constraints:

- 1 <= s.length <= 300
- 1 <= wordDict.length <= 1000
- 1 <= wordDict\[i\].length <= 20
- s and wordDict\[i\] consist of only lowercase English letters.
- All the strings of wordDict are unique.

---

## Solution

### Intuition
`dp[i]` = True if `s[i:]` can be fully segmented using wordDict. For each position `i`, try every word and check if `s[i:i+len(word)] == word` and `dp[i+len(word)]` is True. Building right-to-left avoids recomputing the same suffix segmentability. A [[0.BacktrackingGuide|Backtracking]] solution explores the same suffixes repeatedly. [[Dynamic Programming]] solves each once. Converting `wordDict` to a [[Set]] makes membership checks O(1) instead of O(k).

### State definition and recurrence

**State:** `dp[i]` = True if `s[i:]` can be segmented into dictionary words.

**Recurrence:** `dp[i] = any(s[i:i+len(w)] == w and dp[i+len(w)] for w in wordDict)`.

**Base case:** `dp[n] = True` (empty suffix is always segmentable).

### Approach 1: Top-down memoization

Recursion tries each dictionary word at the current index. The cache avoids revisiting the same suffix.

```python
class Solution:
    def wordBreak(self, s: str, wordDict: list[str]) -> bool:
        word_set = set(wordDict)
        n = len(s)
        memo = {}

        def dp(i: int) -> bool:
            if i == n:
                return True
            if i in memo:
                return memo[i]

            for word in word_set:
                end = i + len(word)
                if end <= n and s[i:end] == word and dp(end):
                    memo[i] = True
                    return True

            memo[i] = False
            return False

        return dp(0)
```

### Approach 2: Bottom-up tabulation

Build dp right-to-left. Use a set for O(1) word lookup.

```python
class Solution:
    def wordBreak(self, s: str, wordDict: list[str]) -> bool:
        word_set = set(wordDict)
        n = len(s)
        dp = [False] * (n + 1)
        dp[n] = True

        for i in range(n - 1, -1, -1):
            for word in word_set:
                end = i + len(word)
                if end <= n and s[i:end] == word:
                    dp[i] = dp[end]
                if dp[i]:
                    break

        return dp[0]
```

> `dp[n] = True` is the sentinel: an empty remainder needs no more words. The early `break` once `dp[i]` is True is a safe optimization because we only need one valid segmentation.

### Complexity
- **Time:** O(n * m * L) where m = number of words and L = max word length (substring comparison cost). Practically O(n * total characters in dict).
- **Space:** O(n) for the dp array, plus O(total dict characters) for the set.

### Key concepts to review
- [[Dynamic Programming]] - each suffix segmentability is computed once and reused.
- [[Set]] - converting wordDict to a set enables O(1) average-case membership tests.
- [[0.BacktrackingGuide|Backtracking]] - naive alternative that revisits suffixes without caching.
- [[Memoization]] - top-down alternative shown in Approach 1.
- [[11.LongestIncreasingSubsequence]] - similar right-to-left or left-to-right DP building on earlier answers.

### Common pitfalls
- Not converting wordDict to a set (list lookup is O(k) per check, making overall complexity worse).
- Checking `s[i:end] in word_set` instead of `s[i:end] == word` inside the loop causes a subtle mismatch with the `end` computation.
- Forgetting `dp[n] = True` means no position will ever become True.
- The early `break` optimization is valid only for existence (True/False), not for counting all segmentations.
