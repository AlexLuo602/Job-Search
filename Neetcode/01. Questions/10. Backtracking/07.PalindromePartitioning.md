# [131. Palindrome Partitioning](https://leetcode.com/problems/palindrome-partitioning/)


Given a string s, partition s such that every substring of the partition is a palindrome. Return all possible palindrome partitioning of s.

A palindrome string is a string that reads the same backward as forward.

 

**Example 1:**
```
Input: s = "aab"
Output: [["a","a","b"],["aa","b"]]
```
**Example 2:**
```
Input: s = "a"
Output: [["a"]]
```

Constraints:

- 1 <= s.length <= 16
- s contains only lowercase English letters.

---

## Solution

### Intuition
We use [[0.BacktrackingGuide|Backtracking]] to try every way to cut the string. At each position `start`, we try all prefixes `s[start:end+1]`. If a prefix is a palindrome, we add it to the current partition and recurse from `end+1`. When `start` reaches the end of the string, the entire string has been validly partitioned and we record the result.

### Approach
At each recursive call, loop over all possible end indices for the next substring. Only recurse if the candidate substring is a palindrome. Undo by popping the last added substring.

```python
class Solution:
    def partition(self, s: str) -> list[list[str]]:
        res: list[list[str]] = []
        path: list[str] = []

        def is_palindrome(sub: str) -> bool:
            return sub == sub[::-1]

        def backtrack(start: int) -> None:
            if start == len(s):         # entire string partitioned
                res.append(path[:])
                return
            for end in range(start + 1, len(s) + 1):
                sub = s[start:end]
                if is_palindrome(sub):
                    path.append(sub)    # choose
                    backtrack(end)      # explore from the character after this cut
                    path.pop()          # undo

        backtrack(0)
        return res
```

> The palindrome check `sub == sub[::-1]` is O(L) per call. For larger inputs, precomputing a 2D palindrome table with [[Dynamic Programming]] reduces each check to O(1), trading space for time. Here the constraint (`s.length <= 16`) keeps the naive check acceptable.

### Complexity
- **Time:** O(N * 2^N). There are 2^(N-1) ways to place cuts, and each palindrome check and copy is O(N).
- **Space:** O(N). Recursion depth is at most N (one cut per character).

### Key concepts to review
- [[0.BacktrackingGuide|Backtracking]] - try each prefix, recurse if valid palindrome, undo on return.
- [[Recursion]] - depth bounded by the number of cuts, at most N levels.
- [[Dynamic Programming]] - can precompute palindrome table to reduce check from O(N) to O(1) per substring.
- [[0.TwoPointerGuide|Two Pointer]] - alternative way to implement `is_palindrome` without string reversal.

### Common pitfalls
- Using `range(start, len(s))` for `end` instead of `range(start + 1, len(s) + 1)`, which would make slicing off-by-one (missing single characters or the last character).
- Checking `if start > len(s)` as the base case instead of `if start == len(s)`, which still works but adds an unnecessary extra call.
- Appending `path` directly instead of `path[:]` to `res`.
- Forgetting to pop after the recursive call, corrupting future branches.
