# [79. Word Search](https://leetcode.com/problems/word-search/)


Given an m x n grid of characters board and a string word, return true if word exists in the grid.

The word can be constructed from letters of sequentially adjacent cells, where adjacent cells are horizontally or vertically neighboring. The same letter cell may not be used more than once.

 

**Example 1:**

![[word-search-example.svg]]

```
Input: board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"
Output: true
```

**Example 2:**
```
Input: board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "SEE"
Output: true
```
**Example 3:**
```
Input: board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCB"
Output: false
```

Constraints:

- m == board.length
- n = board[i].length
- 1 <= m, n <= 6
- 1 <= word.length <= 15
- board and word consists of only lowercase and uppercase English letters.

### Follow up: Could you use search pruning to make your solution faster with a larger board?

## Solution

### Intuition
This is [[0.BacktrackingGuide|Backtracking]] on a [[Matrix Traversal]] grid. Starting from each cell that matches `word[0]`, we explore four directions depth-first. The "undo" step is marking a visited cell with a sentinel and restoring it afterward, so sibling branches see the original board state.

### Approach
Try each cell as a starting point. In the recursive helper, mark the current cell to prevent revisiting, recurse into all four neighbors for the next character, then restore the cell regardless of whether the branch succeeded or failed.

```python
class Solution:
    def exist(self, board: list[list[str]], word: str) -> bool:
        rows, cols = len(board), len(board[0])

        def backtrack(r: int, c: int, idx: int) -> bool:
            if idx == len(word):        # all characters matched
                return True
            if r < 0 or r >= rows or c < 0 or c >= cols:
                return False
            if board[r][c] != word[idx]:
                return False

            temp = board[r][c]
            board[r][c] = "#"           # mark visited (in-place, no extra array)

            found = (
                backtrack(r + 1, c, idx + 1) or
                backtrack(r - 1, c, idx + 1) or
                backtrack(r, c + 1, idx + 1) or
                backtrack(r, c - 1, idx + 1)
            )

            board[r][c] = temp          # undo: restore cell for other paths

            return found

        for r in range(rows):
            for c in range(cols):
                if backtrack(r, c, 0):
                    return True
        return False
```

> Temporarily overwriting `board[r][c]` with `"#"` is the in-place "mark visited" trick. It avoids an extra O(m*n) boolean array and the undo is a simple reassignment. The sentinel must be a character that cannot appear in the word; `"#"` works because the constraints limit the board to English letters.

### Complexity
- **Time:** O(M * N * 4^L) where L is the length of the word. Each starting cell can branch 4 ways up to L levels deep.
- **Space:** O(L). The recursion stack depth is bounded by the word length.

### Key concepts to review
- [[0.BacktrackingGuide|Backtracking]] - in-place mark/restore pattern on a 2D grid.
- [[Matrix Traversal]] - four-direction DFS from each candidate starting cell.
- [[DFS|Depth-First Search]] - the recursive exploration strategy used here.
- [[Recursion]] - base cases: index out of bounds, character mismatch, word fully matched.

### Common pitfalls
- Not restoring the cell after backtracking, causing later starting cells to see a corrupted board.
- Checking bounds before checking the character, which is fine, but a combined guard at the top of the function is cleaner.
- Returning early on the first `True` from a neighbor without short-circuit `or`, which wastes time exploring unnecessary branches.
- Using a separate `visited` array but forgetting to unset entries on backtrack.
