# 11. Container With Most Water

You are given an integer array height of length n. There are n vertical lines drawn such that the two endpoints of the ith line are (i, 0) and (i, height[i]).

Find two lines that together with the x-axis form a container, such that the container contains the most water.

Return the maximum amount of water a container can store.

Notice that you may not slant the container.

 

**Example 1:**

![[container-with-most-water.svg]]

```
Input: height = [1,8,6,2,5,4,8,3,7]
Output: 49
Explanation: The above vertical lines are represented by array [1,8,6,2,5,4,8,3,7]. In this case, the max area of water (blue section) the container can contain is 49.
```

**Example 2:**
```
Input: height = [1,1]
Output: 1
```

Constraints:

- n == height.length
- 2 <= n <= 105
- 0 <= height[i] <= 104

---

## Solution

### Intuition
Area is `width * min(left height, right height)`. Start with the widest possible container (both ends) and shrink inward. The key insight: moving the taller wall in can never help because width only decreases and the shorter wall still caps the height, so we always move the shorter wall, hoping to find a taller one.

### Approach 1: Brute force (for contrast)
```python
# Try every pair of lines
for i in range(n):
    for j in range(i + 1, n):
        best = max(best, (j - i) * min(height[i], height[j]))
```
O(n^2), which is too slow for n up to 10^5.

### Approach 2: Greedy two pointers
Use [[0.TwoPointerGuide|Two Pointer]] at both ends. Compute the area, update the max, then discard the shorter wall by stepping its pointer inward. Repeat until the pointers meet.

```python
from typing import List

class Solution:
    def maxArea(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        best = 0
        while left < right:
            area = (right - left) * min(height[left], height[right])
            best = max(best, area)
            # Move the shorter wall: it is the limiting factor, and
            # keeping it can only yield smaller areas as width shrinks.
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
        return best
```

> This is a [[0.GreedyGuide|Greedy]] argument: discarding the shorter wall is safe because any container still using it would be both narrower and no taller, so it cannot beat what we already measured.

### Complexity
- **Time:** O(n). Each step moves one pointer; they meet after n steps total.
- **Space:** O(1). Only pointer and running-max variables.

### Key concepts to review
- [[0.TwoPointerGuide|Two Pointer]] - converging ends with a greedy discard rule.
- [[0.GreedyGuide|Greedy]] - the local choice (drop the shorter wall) is provably globally optimal.
- [[05.TrappingRainWater]] - sibling problem also driven by the shorter of two walls.

### Common pitfalls
- Moving the taller wall, or both walls, which can skip the optimal container.
- Multiplying by width incorrectly (it is `right - left`, not `right - left + 1`).
- Tracking only the current area instead of the running maximum.
