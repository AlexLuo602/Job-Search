# 125. Valid Palindrome

A phrase is a palindrome if, after converting all uppercase letters into lowercase letters and removing all non-alphanumeric characters, it reads the same forward and backward. Alphanumeric characters include letters and numbers.

Given a string s, return true if it is a palindrome, or false otherwise.

 

**Example 1:**
```
Input: s = "A man, a plan, a canal: Panama"
Output: true
Explanation: "amanaplanacanalpanama" is a palindrome.
```
**Example 2:**
```
Input: s = "race a car"
Output: false
Explanation: "raceacar" is not a palindrome.
```
**Example 3:**
```
Input: s = " "
Output: true
Explanation: s is an empty string "" after removing non-alphanumeric characters.
Since an empty string reads the same forward and backward, it is a palindrome.
```

Constraints:

- 1 <= s.length <= 2 * 105
- s consists only of printable ASCII characters.

---

## Solution

### Intuition
A palindrome reads the same from both ends, so we compare characters moving inward from both sides. The twist is that we must skip non-alphanumeric characters and compare case-insensitively. The [[0.TwoPointerGuide|Two Pointer]] technique lets us do this in one pass with no extra string allocation.

### Approach
Place one pointer at each end. Advance each pointer past any non-alphanumeric character, then compare the two characters in lowercase. If they ever differ the string is not a palindrome; otherwise step both pointers inward until they meet.

```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        i, j = 0, len(s) - 1
        while i < j:
            # Skip junk from the left; guard i < j so we never run past j
            while i < j and not s[i].isalnum():
                i += 1
            while i < j and not s[j].isalnum():
                j -= 1
            if s[i].lower() != s[j].lower():
                return False
            i += 1
            j -= 1
        return True
```

> The inner `i < j` guard inside each skip loop is essential: without it, a string of all non-alphanumeric characters would let a pointer walk off its end before the outer condition rechecks.

### Walkthrough
Tracing `s = "a, A"` (skips the comma and space, case-insensitive):

| i | j | s[i] | s[j] | note |
|---|---|------|------|------|
| 0 | 3 | a | A | both alnum; 'a' == 'a' -> step inward |
| 1 | 2 | , | (space) | skip loop pushes i to 2, then stops (i < j fails) |
| 2 | 2 | (space) | (space) | comparison still runs: s[2] matches itself, i=3, j=1 |
| 3 | 1 | - | - | outer check: i not < j, loop ends, return True |

Final output: **True**.

### Complexity
- **Time:** O(n). Each pointer traverses the string at most once.
- **Space:** O(1). Comparison is done in place with no copy of the filtered string.

### Key concepts to review
- [[0.TwoPointerGuide|Two Pointer]] - converge from both ends, the foundation for this whole folder.
- [[02.TwoSumII]] - same converging-pointer pattern on a sorted array.

### Common pitfalls
- Forgetting the `i < j` guard inside the skip loops, which can index out of range on all-punctuation input.
- Comparing without `.lower()`, treating 'A' and 'a' as different.
- Building a new filtered string (O(n) space) when in-place comparison suffices.
