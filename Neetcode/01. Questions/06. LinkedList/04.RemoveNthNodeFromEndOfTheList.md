# 19. Remove Nth Node From End of List


Given the head of a linked list, remove the nth node from the end of the list and return its head.

 

**Example 1:**

![[remove-nth-node-example.svg]]

```
Input: head = [1,2,3,4,5], n = 2
Output: [1,2,3,5]
```
**Example 2:**
```
Input: head = [1], n = 1
Output: []
```
**Example 3:**
```
Input: head = [1,2], n = 1
Output: [1]
```

Constraints:

The number of nodes in the list is sz.
- 1 <= sz <= 30
- 0 <= Node.val <= 100
- 1 <= n <= sz
 

### Follow up: Could you do this in one pass?

---

## Solution

### Intuition
To find the nth node from the end in one pass, use [[0.TwoPointerGuide|Two Pointer]] with a fixed gap: advance a `fast` pointer n steps ahead, then move both until `fast` hits the end. Now `slow` sits just before the target. A [[Dummy Head|Dummy Node]] makes removing the head itself a non-special case.

### Approach: Optimal (one pass)
Start both pointers at a dummy node. Move `fast` n steps forward, then advance both until `fast.next` is None. `slow.next` is the node to delete.

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
from typing import Optional

class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)  # handles removing the original head uniformly
        slow = fast = dummy
        for _ in range(n):         # open a gap of n nodes
            fast = fast.next
        while fast.next:           # walk both until fast is at the last node
            slow = slow.next
            fast = fast.next
        slow.next = slow.next.next # splice out the target
        return dummy.next
```

> Anchoring both pointers at the dummy (not at `head`) guarantees `slow` lands on the node before the target even when the target is the head, so no separate head-removal branch is needed.

### Walkthrough
Input `1 -> 2 -> 3 -> 4 -> 5`, `n = 2`:
- After moving `fast` 2 steps: `slow` at dummy, `fast` at node 2.
- Advance both until `fast.next is None`: `slow` at node 3, `fast` at node 5.
- `slow.next` is node 4, remove it.

Final output: `1 -> 2 -> 3 -> 5`.

### Complexity
- **Time:** O(n). Single traversal of the list.
- **Space:** O(1). Two pointers only.

### Key concepts to review
- [[0.TwoPointerGuide|Two Pointer]] - a fixed-gap window converts "nth from end" into "current node"; see [[03.ReorderList]].
- [[Dummy Head|Dummy Node]] - removes the head-deletion edge case; see [[02.MergeTwoLinkedList]].
- [[Linked List]] - splice a node out by relinking the predecessor.

### Common pitfalls
- Starting pointers at `head` instead of the dummy, which breaks when deleting the first node.
- Looping while `fast` is not None rather than `fast.next`, leaving `slow` one node too far.
- Off-by-one in the gap: advance exactly n steps, not n+1.
