# 143. Reorder List


You are given the head of a singly linked-list. The list can be represented as:

L0 → L1 → … → Ln - 1 → Ln
Reorder the list to be on the following form:

L0 → Ln → L1 → Ln - 1 → L2 → Ln - 2 → …
You may not modify the values in the list's nodes. Only nodes themselves may be changed.

 

**Example 1:**

![[reorder-list-example.svg]]

```
Input: head = [1,2,3,4]
Output: [1,4,2,3]
```

**Example 2:**

```
Input: head = [1,2,3,4,5]
Output: [1,5,2,4,3]
```

Constraints:

- The number of nodes in the list is in the range [1, 5 * 104].
- 1 <= Node.val <= 1000

---

## Solution

### Intuition
The reorder interleaves the front half with the reversed back half. So the plan combines three classic moves: find the middle with [[Fast & Slow Pointers|Fast and Slow Pointers]], apply [[Linked List Reversal|In-place Reversal]] to the second half, then merge the two halves by alternating nodes.

### Approach: Optimal
1. Find the middle using slow/fast pointers.
2. Split and reverse the second half (see [[01.ReverseLinkedList]]).
3. Weave the two halves together, taking one node from each.

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
from typing import Optional

class Solution:
    def reorderList(self, head: Optional[ListNode]) -> None:
        # 1. find middle: slow ends at the end of the first half
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        # 2. reverse the second half and cut the first half loose
        second = slow.next
        slow.next = None
        prev = None
        while second:
            nxt = second.next
            second.next = prev
            prev = second
            second = nxt
        second = prev  # new head of the reversed back half

        # 3. interleave the two halves
        first = head
        while second:
            t1, t2 = first.next, second.next
            first.next = second
            second.next = t1
            first, second = t1, t2
```

> Cutting `slow.next = None` is essential: without it the first half still points into the second half, creating a cycle when you weave them back together.

### Complexity
- **Time:** O(n). Three linear passes: find middle, reverse, merge.
- **Space:** O(1). All rewiring is in place.

### Key concepts to review
- [[Fast & Slow Pointers|Fast and Slow Pointers]] - locate the midpoint in one pass; see [[07.LinkedListCycle]].
- [[Linked List Reversal|In-place Reversal]] - reverse the back half; see [[01.ReverseLinkedList]].
- [[Linked List]] - careful pointer juggling while interleaving.

### Common pitfalls
- Not severing the first half (`slow.next = None`), which introduces a cycle.
- Off-by-one on the middle: starting `fast = head.next` puts `slow` at the end of the first half for both even and odd lengths.
- Losing `first.next` or `second.next` during the weave; save both in temporaries first.
