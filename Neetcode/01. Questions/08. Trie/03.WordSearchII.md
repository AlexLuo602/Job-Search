# 212. Word Search II

Given an m x n board of characters and a list of strings words, return all words on the board. Each word must be constructed from letters of sequentially adjacent cells (horizontally or vertically adjacent). The same letter cell may not be used more than once in a word.

**Example 1:**

![[word-search-ii-example.svg]]

```text
Input: board = [["o","a","a","n"],["e","t","a","e"],["i","h","k","r"],["i","f","l","v"]], words = ["oath","pea","eat","rain"]
Output: ["eat","oath"]
```

**Example 2:**

```text
Input: board = [["a","b"],["c","d"]], words = ["abcb"]
Output: []
```

Constraints:
- m == board.length
- n == board\[i\].length
- 1 <= m, n <= 12
- board\[i\]\[j\] is a lowercase English letter
- 1 <= words.length <= 3 * 10^4
- 1 <= words\[i\].length <= 10
- words\[i\] consists of lowercase English letters
- All strings in words are unique

---

## Solution

### Intuition
Checking each word independently with DFS would be O(words * m * n * 4^L), which is too slow when there are up to 30,000 words. The key insight is to build a [[0.TrieGuide|Trie]] from all target words first, then run a single [[0.BacktrackingGuide|Backtracking]] DFS from every cell. The trie lets every DFS step prune entire word families at once: if the current prefix is not in the trie, there is no point continuing.

### Approach
Insert all words into a trie, storing the complete word string at terminal nodes. Run [[DFS|Depth-First Search]] from every board cell. At each step, advance the trie pointer. If the edge is missing, prune immediately. When a terminal node is reached, record the word and set it to `None` to prevent duplicates. Mark cells with a sentinel during recursion and restore them on backtrack.

```python
from typing import Optional


class TrieNode:
    def __init__(self) -> None:
        self.children: dict[str, "TrieNode"] = {}
        self.word: Optional[str] = None  # non-None at terminal nodes


class Solution:
    def findWords(self, board: list[list[str]], words: list[str]) -> list[str]:
        # Build trie from all target words
        root = TrieNode()
        for word in words:
            node = root
            for ch in word:
                if ch not in node.children:
                    node.children[ch] = TrieNode()
                node = node.children[ch]
            node.word = word  # store word at terminal

        rows, cols = len(board), len(board[0])
        result: list[str] = []

        def dfs(r: int, c: int, node: TrieNode) -> None:
            ch = board[r][c]
            if ch not in node.children:
                return  # prune: prefix not in trie

            next_node = node.children[ch]

            if next_node.word:
                result.append(next_node.word)
                next_node.word = None  # deduplicate: clear to avoid re-adding

            board[r][c] = '#'  # mark visited (in-place, avoids extra visited set)
            for dr, dc in [(0, 1), (0, -1), (1, 0), (-1, 0)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < rows and 0 <= nc < cols and board[nr][nc] != '#':
                    dfs(nr, nc, next_node)
            board[r][c] = ch  # restore for other DFS paths

        for r in range(rows):
            for c in range(cols):
                dfs(r, c, root)

        return result
```

> Nulling out `next_node.word` after finding a word is a clean deduplication trick. A further optimization (not shown) is to prune leaf trie nodes after they are found, shrinking the trie and reducing future DFS work.

### Walkthrough
Board (4x4), words = \["oath", "pea", "eat", "rain"\].

1. Trie built: o->a->t->h (word="oath"), p->e->a (word="pea"), e->a->t (word="eat"), r->a->i->n (word="rain").
2. DFS from (1,0)='e' advances to the 'e' node, but none of its neighbors ('o' above, 't' right, 'i' below) matches the node's only child 'a', so the branch dies. DFS from (1,3)='e': neighbor (1,2)='a' matches, advance. From there, neighbor (1,1)='t' reaches the terminal for "eat". Append, clear word.
3. DFS from (0,0)='o': o->a->t->h found via cells (0,0)->(0,1)->(1,1)->(2,1). Append "oath".
4. "pea" and "rain" paths do not exist on the board.
5. Return \["eat", "oath"\].

### Complexity
- **Time:** O(m * n * 4^L) where L is the max word length. The trie prunes branches that do not match any word prefix, making practical performance much better than the worst case.
- **Space:** O(W * L) for the trie where W is the number of words and L is max word length. O(L) recursion stack depth.

### Key concepts to review
- [[0.TrieGuide|Trie]] - builds the multi-word prefix structure. See siblings [[01.ImplementTrie]] and [[02.DesignAddandSearchWordDataStructure]].
- [[0.BacktrackingGuide|Backtracking]] - the DFS explores paths and restores board state on return.
- [[DFS|Depth-First Search]] - the traversal mechanism through board cells.

### Common pitfalls
- Using a visited set instead of in-place marking: the set approach works but costs extra memory and is slightly slower per call.
- Not clearing `node.word` after finding a word, leading to duplicate results when multiple DFS paths reach the same terminal.
- Off-by-one in bounds checking for the four directions.
- Forgetting to restore `board[r][c]` after recursion (leaving '#' permanently).
