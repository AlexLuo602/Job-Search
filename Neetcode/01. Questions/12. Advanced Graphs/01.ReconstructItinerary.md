# 332. Reconstruct Itinerary

Given a list of airline tickets represented by pairs [from, to], reconstruct the itinerary in order. All tickets belong to a man who departs from "JFK". The itinerary must begin with "JFK". If multiple valid itineraries exist, return the one with the smallest lexical order. You must use all tickets exactly once.

**Example 1:**

![[reconstruct-itinerary-example.svg]]

```text
Input: tickets = [["MUC","LHR"],["JFK","MUC"],["SFO","SJC"],["LHR","SFO"]]
Output: ["JFK","MUC","LHR","SFO","SJC"]
```

**Example 2:**

![[advanced-graphs-reconstruct-itinerary-example-2.svg]]

```text
Input: tickets = [["JFK","SFO"],["JFK","ATL"],["SFO","ATL"],["ATL","JFK"],["ATL","SFO"]]
Output: ["JFK","ATL","JFK","SFO","ATL","SFO"]
```

Constraints:
- 1 <= tickets.length <= 300
- tickets[i].length == 2
- from and to consist of uppercase English letters
- The input is guaranteed to have a valid itinerary

---

## Solution

### Intuition
This is an Eulerian path problem: we need to traverse every edge exactly once. Using [[DFS|Depth-First Search]] with Hierholzer's algorithm, we greedily visit destinations in lexicographic order (via a sorted adjacency list) and append each airport to the result only after all outgoing edges from it are exhausted. Reversing the post-order result gives the correct itinerary.

### Approach: Hierholzer's DFS
Sort each adjacency list so we always pick the lexicographically smallest destination first. Perform a [[DFS|Depth-First Search]] that pops the next destination, recurses, then prepends the current node to the result - this post-order insertion naturally handles dead ends.

```python
import collections

class Solution:
    def findItinerary(self, tickets: list[list[str]]) -> list[str]:
        # Build adjacency list sorted for lexicographic order
        graph: dict[str, list[str]] = collections.defaultdict(list)
        for src, dst in sorted(tickets, reverse=True):
            graph[src].append(dst)

        result: list[str] = []

        def dfs(airport: str) -> None:
            while graph[airport]:
                # Pop last = smallest due to reverse-sorted insertion
                next_stop = graph[airport].pop()
                dfs(next_stop)
            result.append(airport)  # WHY: append after all edges consumed

        dfs("JFK")
        return result[::-1]  # WHY: post-order gives reverse of correct itinerary
```

> Inserting tickets in reverse-sorted order and popping from the end achieves O(1) pop while maintaining lexicographic priority - equivalent to using a min-heap but simpler.

### Complexity
- **Time:** O(E log E). Sorting edges takes O(E log E); each edge is visited once.
- **Space:** O(E). Adjacency list stores all tickets; recursion depth is at most E.

### Key concepts to review
- [[DFS|Depth-First Search]] - post-order DFS (Hierholzer's algorithm) finds Eulerian paths
- [[Graph]] - directed multigraph where edges are airline tickets
- [[Sorting]] - lexicographic ordering of destinations via pre-sorted adjacency lists
- [[02.MinCostToConnectAllPoints]] - another advanced graph problem in this set
- [[05.AlienDictionary]] - also uses graph traversal to derive ordering

### Common pitfalls
- Forgetting to reverse the result - post-order DFS builds the itinerary backwards.
- Using a min-heap instead of pre-sorting; both work but pre-sorting with reversed pop is cleaner in Python.
- Not handling the case where a node has no outgoing edges (dead end) - the while loop naturally handles this.
- Sorting tickets ascending then appending (instead of reverse-sort + pop) would require O(n) list removal.
