# 269. Alien Dictionary

There is a new alien language using the English alphabet. The order among letters is unknown. You are given a list of strings words sorted lexicographically by the alien language's rules. Derive the order of letters. Return any valid ordering, or "" if no valid order exists.

**Example 1:**

```text
Input: words = ["wrt","wrf","er","ett","rftt"]
Output: "wertf"
```

**Example 2:**

```text
Input: words = ["z","x"]
Output: "zx"
```

**Example 3:**

```text
Input: words = ["z","x","z"]
Output: ""
```

Constraints:
- 1 <= words.length <= 100
- 1 <= words[i].length <= 100
- words[i] consists of lowercase English letters

---

## Solution

### Intuition
Each adjacent pair of words in the sorted list reveals a precedence constraint between two letters (the first position where they differ). These constraints form a directed graph, and we need a linear ordering that respects all constraints. This is exactly [[Topological Sort]] via Kahn's algorithm (BFS on in-degrees). A cycle in the graph means no valid ordering exists.

### Approach: Build Constraint Graph, then Topological Sort
Compare each adjacent pair of words to extract one directed edge (u -> v means u comes before v). Then run BFS-based topological sort: repeatedly pick nodes with in-degree 0. If the result includes all unique characters, return it; otherwise a cycle exists, return "".

```python
import collections

class Solution:
    def alienOrder(self, words: list[str]) -> str:
        # Initialize adjacency list and in-degree for all unique chars
        adj: dict[str, set[str]] = {c: set() for word in words for c in word}
        in_degree: dict[str, int] = {c: 0 for c in adj}

        # Extract ordering constraints from adjacent word pairs
        for i in range(len(words) - 1):
            w1, w2 = words[i], words[i + 1]
            min_len = min(len(w1), len(w2))
            # WHY: if w1 is a prefix-extension of w2, that's an invalid input
            if len(w1) > len(w2) and w1[:min_len] == w2[:min_len]:
                return ""
            for j in range(min_len):
                if w1[j] != w2[j]:
                    if w2[j] not in adj[w1[j]]:
                        adj[w1[j]].add(w2[j])
                        in_degree[w2[j]] += 1
                    break  # WHY: only the first differing character gives info

        # Kahn's algorithm: BFS topological sort
        queue: collections.deque[str] = collections.deque(
            c for c in in_degree if in_degree[c] == 0
        )
        result: list[str] = []

        while queue:
            c = queue.popleft()
            result.append(c)
            for neighbor in adj[c]:
                in_degree[neighbor] -= 1
                if in_degree[neighbor] == 0:
                    queue.append(neighbor)

        # WHY: cycle detected if not all characters are in result
        return "".join(result) if len(result) == len(in_degree) else ""
```

> Only the first differing character between two adjacent words gives a constraint. All subsequent differing characters are uninformative because the order was already determined at the first difference.

### Complexity
- **Time:** O(C) where C is total length of all words. Comparing adjacent pairs is O(C); topological sort is O(V + E) where V and E are bounded by the alphabet size (26) and C.
- **Space:** O(1) or O(26^2) at most for the graph, since there are at most 26 unique characters.

### Key concepts to review
- [[Topological Sort]] - linear ordering of nodes in a DAG respecting directed edges
- [[BFS|Breadth-First Search]] - Kahn's algorithm uses BFS with in-degree tracking
- [[Graph]] - directed graph where nodes are characters and edges encode ordering
- [[01.ReconstructItinerary]] - another graph traversal problem in this set
- [[06.CheapestFlightsWithinKStops]] - graph with constraints on traversal

### Common pitfalls
- Missing the invalid input case where a longer word appears before its prefix (e.g., ["abc","ab"] should return "").
- Adding duplicate edges without deduplication - causes incorrect in-degree counts. Use a set for adjacency.
- Returning "" only when the result length differs from the number of unique characters, not from the total words count.
- Comparing more than the first differing character between two words.
