# 155. Min Stack


Design a stack that supports push, pop, top, and retrieving the minimum element in constant time.

Implement the MinStack class:

- MinStack() initializes the stack object.
- void push(int val) pushes the element val onto the stack.
- void pop() removes the element on the top of the stack.
- int top() gets the top element of the stack.
- int getMin() retrieves the minimum element in the stack.
 

**Example 1:**
```
Input
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

Output
[null,null,null,null,-3,null,0,-2]

Explanation
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin(); // return -3
minStack.pop();
minStack.top();    // return 0
minStack.getMin(); // return -2
```

Constraints:

- -231 <= val <= 231 - 1
- Methods pop, top and getMin operations will always be called on non-empty stacks.
- At most 3 * 104 calls will be made to push, pop, top, and getMin.

---

## Solution

### Intuition
A normal [[Stack]] gives O(1) push/pop/top but finding the minimum would be O(n). The trick is to store, alongside each value, the minimum of the stack at the moment that value was pushed. Then `getMin` is just reading the top's bundled minimum in O(1).

### Approach
Keep one stack of pairs `(val, current_min)`. On push, the new minimum is `min(val, previous_min)` where the previous minimum is the top's second field (or `val` if empty). Pop, top, and getMin all read or remove the top in O(1).

```python
class MinStack:
    def __init__(self) -> None:
        # each entry is (value, min-of-stack-at-this-point)
        self.stack: list[tuple[int, int]] = []

    def push(self, val: int) -> None:
        # running minimum carries forward from the previous top
        cur_min = val if not self.stack else min(val, self.stack[-1][1])
        self.stack.append((val, cur_min))

    def pop(self) -> None:
        self.stack.pop()

    def top(self) -> int:
        return self.stack[-1][0]

    def getMin(self) -> int:
        return self.stack[-1][1]
```

> Bundling the min with each value means a pop automatically restores the previous minimum, no recomputation needed.

### Walkthrough
Operations `push(-2), push(0), push(-3), getMin, pop, top, getMin`:

| op | stack (val, min) | returns |
|----|------------------|---------|
| push(-2) | `[(-2,-2)]` | |
| push(0) | `[(-2,-2),(0,-2)]` | |
| push(-3) | `[(-2,-2),(0,-2),(-3,-3)]` | |
| getMin | unchanged | `-3` |
| pop | `[(-2,-2),(0,-2)]` | |
| top | unchanged | `0` |
| getMin | unchanged | `-2` |

### Complexity
- **Time:** O(1) for every operation. Each is a single list append, pop, or index.
- **Space:** O(n). Each element stores its value plus a cached minimum.

### Key concepts to review
- [[Stack]] - LIFO base structure; augmenting each entry with metadata is a common pattern (see [[01.ValidParentheses]]).
- [[Space-Time Tradeoff]] - storing an extra min per element buys O(1) minimum lookups.

### Common pitfalls
- Computing the new minimum against `val` only and forgetting the previous min, breaking monotonic decreases.
- Using a single scalar `min` variable instead of per-entry mins, which cannot recover the prior minimum after a pop.
- Handling the empty-stack case wrong on the very first push.
